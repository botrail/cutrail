# 解析面の復元と STEP 出力

[English](../brep-export.md) | 日本語

加工後の素材はメッシュだが、3 軸・フラットエンドミルの水平送りと突込みでできた面は、平面と軸が +Z の円柱面に復元して B-rep として書き出せる。

```rust
let brep = engine.reconstruct_brep()?;
println!("faces (planes, cylinders) = {:?}", brep.surface_counts());
println!("edges (lines, arcs, polylines) = {:?}", brep.curve_counts());
brep.check(1e-6)?;                      // ループの閉性と、稜線の端点が面の上にあることを検査する
engine.write_step(std::fs::File::create("machined.step")?, "machined")?;
```

## 仕組み

1. **由来情報。** メッシュブーリアンは結果の三角形ごとに「どの入力から来たか」を保持する。エンジンは素材と掃引体積の凸な部分ごとに固有の ID を与え、工具の半径と始点・終点の姿勢を記録する。
2. **分類。** 由来が軸 +Z のフラットエンドミルの水平送りまたは突込みなら、既知の幾何から面を決める：底面（先端の高さの水平面）、直線部の側壁（経路から半径 r の鉛直面）、両端の円柱（先端の XY を軸、半径 r）。半径はメッシュの多角形ではなく工具の真の半径。素材は三角形の平面。それ以外（ボール・ブルノーズ、傾いた軸、ランプ、円弧移動の側面）は三角形自身の平面（ファセット）。
3. **面。** 同じ面で辺を共有する三角形をまとめる。重なる経路の底面は 1 つの面になる。180° を超える円柱面は角度で 2 つに分ける。
4. **稜線。** 面の境界をたどってループを作り、3 面以上が集まる頂点で分ける。平面同士は直線、水平面と円柱は円弧、鉛直面と円柱や円柱同士は鉛直な直線、それ以外は折れ線。頂点は接するすべての面に投影して揃える。
5. **STEP。** AP214 の `MANIFOLD_SOLID_BREP`。面は `PLANE` / `CYLINDRICAL_SURFACE`、稜線は `LINE` / `CIRCLE` / `POLYLINE`、外周は `FACE_OUTER_BOUND`、穴は `FACE_BOUND`。

## 例

| 形状 | 面（平面, 円柱） | 稜線（直線, 円弧, 折れ線） |
|---|---|---|
| 貫通溝（Ø4） | (10, 0) | (24, 0, 0) |
| 止まり穴（Ø4） | (7, 2) | (14, 4, 0) |
| 長円の溝（Ø3） | (9, 2) | (20, 4, 0) |
| 重なる 3 パスのポケット（Ø3） | (9, 6) | (24, 12, 0) |

truck-stepio で読み戻した体積はエンジンの体積と 1% 以内で一致し、閉じたメッシュとして取り込める。

## 制限

- 解析面になるのは 3 軸・フラットエンドミルの水平送りと突込みの結果だけ。それ以外の面はファセットとして同じ STEP に含まれる。
- 接する形状（円柱が壁に接線で接する、穴が素材の面に接する）では頂点の揃え込みが不安定になることがある。
- 検証はメッシュ化して読み戻す方法で行っている。市販 CAD での確認は利用者側で行う。
